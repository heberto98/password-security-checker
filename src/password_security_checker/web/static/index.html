      Aprender, no certificar. Esta herramienta usa una heurística educativa. La puntuación no mide de forma absoluta la resistencia a ataques ni comprueba si una contraseña se ha filtrado.

      BAJO EL CAPÓ

      Reglas claras. Sin caja negra.

      El núcleo Python evalúa longitud, composición, repeticiones y secuencias. La longitud suma puntos; los patrones detectados los reducen. La diversidad se describe, pero no añade puntos.

      Entender la puntuación y sus límites

      Cinco puntos por punto de código, hasta 100. Se restan 25 por cada tipo de patrón. Con patrones, el máximo es 69; por debajo de 12 puntos de código, el máximo es 39.

      Niveles: baja (0–39), media (40–69), alta (70–100). No detecta contraseñas comunes, bloques repetidos, datos personales ni patrones de teclado. Una entrada predecible puede obtener una puntuación alta.

      TUS DATOS

      Sin registro de contraseñas.

      No usamos bases de datos, cookies, almacenamiento del navegador, analíticas ni servicios externos. La entrada se procesa en memoria y se elimina del campo al enviarla.

      El navegador y Python pueden mantener copias temporales en memoria: no se garantiza su borrado seguro. Si alojas la web en otro equipo, la contraseña viajará a ese servidor.
